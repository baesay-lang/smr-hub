# SMR 레퍼런스 허브 (비공개)

소형모듈원자로(SMR) 업무용 정적 HTML 자료 모음. 빌드 과정 없음 — `index.html`을 열면 됨.

## 페이지
- `index.html` — 랜딩 허브
- `SMR-developers.html` — 개발사 현황 (단계·인허가)
- `SMR-licensing-tracks.html` — 인허가 트랙별 분류
- `SMR-reactor-types.html` — 노형 분류 (경수로/비경수로)
- `SMR-reference.html` — 미국 CFR 규정 레퍼런스
- `SMR-dev-xenergy.html` — X-energy / Xe-100 상세
- `LCOE_Calculator.html` — LCOE 계산기

## 호스팅
정적 사이트(Netlify/Cloudflare Pages 등). 루트 진입점 = `index.html`.

> ⚠️ 인허가·사업 현황은 빠르게 변함 — 보고 직전 각 규제기관·개발사 공시로 재확인 권장.
