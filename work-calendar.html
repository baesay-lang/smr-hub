프로그램 다운로드 (zip)

설치 후에는 실행할 때마다 최신 버전으로 자동 업데이트됩니다

설치 (처음 1회, 10분)

  1. Python 설치 — python.org에서 받아 실행. 첫 화면의 "Add python.exe to PATH"에 반드시 체크 후 [Install Now] (이미 있으면 건너뛰기)
  2. 위 zip 다운로드 → 압축 풀기 → 폴더째 문서 폴더로 옮기기 (예: 문서\주간업무캘린더)
  3. 폴더 안 run.bat 실행 → 첫 실행은 필요한 것들을 자동으로 받느라 3~5분 걸립니다. 이후 브라우저가 자동으로 열립니다
  4. run.bat 우클릭 → 바로 가기 만들기 → 바탕화면에 두면 다음부터 아이콘으로 실행
다음부터는 run.bat만 실행하면 됩니다. 실행할 때마다 최신 버전을 자동 확인해 스스로 업데이트되므로 다시 받을 필요가 없습니다 (내 기록·설정은 그대로 유지, 인터넷이 안 되면 그냥 실행).
바탕화면이 아닌 "문서" 폴더에 두세요. 회사 보안정책상 일부 폴더에서는 실행이 차단됩니다. 첫 실행에서 검은 창에 오류가 보이면 창을 닫고 한 번 더 실행해 보세요.

주요 기능

달력에서 직접 기록빈 칸 클릭으로 입력, 드래그로 이동·조절. 팀 업무코드 목록에서 선택
일정 자동 생성임의 배치 / 최근 1개월 이력 / 즐겨찾기 중심 / 전주 복사 — 잔여 시간만 채우기도 가능
주차별 자동 저장수정 즉시 저장되어 몇 주 전 기록도 ◀▶로 그대로 조회
Outlook 연동기존 일정 가져오기 + 완성본 등록 (중복 없음, 기존 주간업무보고 추출과 호환)
Excel 주간업무보고보고 있는 주=금주, 다음 주=차주로 회사 양식 그대로 출력
휴무 처리공휴일 자동 휴무, 요일 칩 클릭으로 연차 지정

자주 묻는 것

팀 코드 추가 config\teams\에 기존 JSON을 복사해 팀명·코드만 수정하면 앱에서 자동 인식됨
근무시간이 다른 부서 앱 좌측 사이드바에서 출퇴근·점심 시간을 팀별로 저장 가능
기록 백업 앱 툴바의 [내보내기] → [전체 기록 백업 (zip)]
Outlook 버튼이 비활성 데스크톱 Outlook이 설치·로그인된 PC에서만 활성화됨
의견·오류 신고 앱 사이드바의 [의견 보내기] — 개선 의견·기능 오류·팀 추가 요청을 파일 첨부와 함께 보낼 수 있음
Python을 왜 따로 까나 예전엔 설치 파일에 Python을 넣어 배포했는데, "다른 실행 파일을 품고 조용히 실행"하는 구조라 백신이 오탐(Trojan:…!ml)으로 차단함. python.org 공식 파일은 MS 서명이 있어 경고 없이 깔림
