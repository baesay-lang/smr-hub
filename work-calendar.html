설치 프로그램 다운로드 (Setup.exe)

항상 최신 버전이 설치됩니다 · 무설치 zip 버전도 있음

설치 (처음 1회)

  1. PC에 Python 3.10 이상 설치 확인 (python --version)
  2. Setup.exe 실행 → 안내에 따라 다음 → 설치 (필요 패키지까지 자동 설치, 1~3분)
  3. 바탕화면의 "주간업무 캘린더" 아이콘으로 실행
설치 후에는 아이콘만 실행하면 됩니다. 실행할 때마다 최신 버전을 자동 확인해 스스로 업데이트되므로 재설치가 필요 없습니다 (내 기록·설정은 그대로 유지, 인터넷이 안 되면 그냥 실행). 제거는 Windows 설정 → 앱 → "주간업무 캘린더".
Windows 보안 경고(SmartScreen)가 뜨면 "추가 정보" → "실행"을 누르면 됩니다 (서명 없는 사내 배포 프로그램이라 표시되는 안내).

주요 기능

달력에서 직접 기록빈 칸 클릭으로 입력, 드래그로 이동·조절. 팀 업무코드 목록에서 선택
일정 자동 생성임의 배치 / 최근 1개월 이력 / 즐겨찾기 중심 / 전주 복사 — 잔여 시간만 채우기도 가능
주차별 자동 저장수정 즉시 저장되어 몇 주 전 기록도 ◀▶로 그대로 조회
Outlook 연동기존 일정 가져오기 + 완성본 등록 (중복 없음, 기존 주간업무보고 추출과 호환)
Excel 주간업무보고보고 있는 주=금주, 다음 주=차주로 회사 양식 그대로 출력
휴무 처리공휴일 자동 휴무, 요일 칩 클릭으로 연차 지정

자주 묻는 것

팀 코드 추가 config\teams\에 기존 JSON을 복사해 팀명·코드만 수정하면 앱에서 자동 인식됨
근무시간이 다른 부서 앱 좌측 사이드바에서 출퇴근·점심 시간을 팀별로 저장 가능
기록 백업 앱의 [보고서▾] → [전체 기록 백업 (zip)]
Outlook 버튼이 비활성 데스크톱 Outlook이 설치·로그인된 PC에서만 활성화됨
